SETUP
⚙️ Setup Needed
Firebase isn't configured yet
This game needs a free Firebase Realtime Database to sync players across phones.

Steps:
1. Go to console.firebase.google.com
2. Create a project (free)
3. Add a Realtime Database → start in test mode
4. Project Settings → Web app → copy the config
5. Paste it into FIREBASE_CONFIG near the top of the script in this file

Everything else already works — this is the only step left.
How to Play
1
Gather Your Group
2 to 10 players. One person creates the game and shares the code.
2
Everyone Joins
Others enter the code and their name to join the lobby.
3
Answer Together
A question appears — pick the player you think fits best. Nobody sees the answers until everyone has picked.
4
Score as a Team
If every single player picked the same person, the team earns 1 point.
5
Reach the Target
Hit your target score before the questions run out and the whole team wins.
🎯 Goal of the Game
This isn't about winning against each other — it's about finding out how well your group thinks alike.
